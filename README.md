# Currículo Front-end em HTML

Página de currículo profissional criada em HTML e CSS, com layout responsivo e componentes visuais para apresentar formação, experiências acadêmicas e competências técnicas.

## Visão geral

- Estrutura semântica em HTML.
- Estilos responsivos para telas menores.
- Seções de perfil, formação, idiomas, projetos e competências.
- Cartões de competências com links para documentação das tecnologias.
- Interações leves no navegador usando JavaScript.

## Tecnologias

- HTML5
- CSS3
- JavaScript puro

## Como visualizar

Não há dependências nem etapa de build. Clone o repositório e abra `curriculo-github.html` no navegador:

```bash
git clone https://github.com/Jhosa-codes/projeto_curriculo_formato_ats_front_end_ferrametas.git
cd projeto_curriculo_formato_ats_front_end_ferrametas
```

Também é possível publicar o arquivo como site estático no GitHub Pages ou em outro host compatível com HTML estático.

## Estrutura

```text
curriculo-github.html   # Página completa com marcação, estilos e interações
```

## Acessibilidade e conteúdo

A página usa títulos por seção, links com rótulos e ajustes de layout para larguras menores. A renderização pode variar conforme navegador e leitor de tela; valide a versão final antes de usar como currículo oficial.

Os dados de formação e experiência exibidos no HTML pertencem ao currículo apresentado na página. Revise e atualize essas informações antes de compartilhar ou usar em candidaturas.
